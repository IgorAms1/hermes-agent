*Designed by Igor, 29 May 2026. Based on real Intercom inbound analysis.*

## TL;DR

4-week enablement sprint для Кати + Никиты. Sales Navigator Advanced. ICP: mid-market/commercial enterprise, Technology/Finance, US/UK/DACH/NL.

## Strong Inbound Signals (из Intercom)

- AWX / Ansible Tower / Red Hat AAP alternative
- Ansible at scale
- SSO / OIDC / LDAP / Active Directory
- RBAC
- Audit logs / execution history
- Runners / distributed execution
- Production instances
- Node count
- SLA / support
- Pricing / quote / procurement

## Lead Patterns

**Good:**
- The Scaler — использует Ansible, хочет controlled interface
- The Complier — SSO, RBAC, audit, identity, compliance
- The Professional — конкретный контекст (instances, nodes, production, SLA)
- The Integrator — reseller/SI/MSP от имени клиента

**Bad:**
- Hobbyist / homelab
- Debug-only community user
- Support-only user
- Feature-demanding free user без бюджета

## Role Split

- **Katya**: commercial lead — firmographics, account prioritization, buying committee mapping, commercial outreach, founder-led dialogue
- **Nikita**: technical presales — technical signal validation, support triage, architecture validation, GitHub/job posts/engineering blogs

## Sales Navigator Advanced

Shared lists, TeamLink, coordination, duplicate prevention. Core too individual, Advanced Plus overkill.

## Hunting Motions

1. Incumbent Alternative — AWX / Ansible Tower / Red Hat AAP
2. AAP cost / complexity / scaling pressure
3. Governed Automation — SSO, OIDC, LDAP, RBAC, audit, compliance
4. Ansible at Scale — runners, distributed execution, multiple environments, node growth
