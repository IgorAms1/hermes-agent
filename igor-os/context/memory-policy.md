# Igor OS Memory Policy

## Remember Durable, Useful Context

Store or suggest storing:

- Long-term goals.
- Stable preferences.
- Repeated workflows.
- Ongoing projects.
- Partner/customer context when non-sensitive.
- Personal style preferences.
- Hobby patterns and repeated observations.
- Dutch vocabulary or phrases Igor wants to retain.
- Training/fishing patterns that recur across sessions.

## Do Not Permanently Store

Do not store:

- Secrets, API keys, passwords, tokens, private keys.
- Raw `.env` contents.
- Private company confidential data.
- Sensitive personal details unless Igor explicitly asks.
- Raw emotional venting unless Igor asks to remember a specific lesson.
- Medical details beyond high-level training constraints unless explicitly requested.

## Memory Candidate Format

When a workflow surfaces durable memory, include:

```text
Memory candidate:
- What:
- Why it matters:
- Sensitivity: low / medium / high
- Suggested storage: remember / keep local only / do not store
```

Ask before storing anything sensitive or work-related.
