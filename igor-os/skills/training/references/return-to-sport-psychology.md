# Return-to-Sport Psychology (МТБ / BJJ)

Igor's core pattern: **all-or-nothing** — either goes 100% or avoids entirely. After injury or hard crash, the fear loop activates:

> 100% push → pain/trauma → avoidance (months) → shame → 100% push again

The mechanism is **shame escalation**: "I forgot technique → I'm embarrassed → I must prove I can still do it → jump higher than ready → crash/hurt → avoid for months."

## Core Principle

**Technique not flowing = day not yours.** Do a victory lap and go home. No new elements, no proving anything.

The paradox: *the less you push on the first sessions back, the faster you return to full capacity.*

## MTB Return Protocol

1. **First ride back:** flat / easy street, 45 min, no jumps. Rebuild bike feel.
2. **Second ride:** back to dirt, but **only the small feature line** (tables, x-ups, eurotables) — the one Igor already knows clean. 3 clean passes → done.
3. **Midline / big features:** only after 3 consecutive clean small-line sessions. Not "almost got it" — clean.
4. **Pillow / no-handers:** only if tailbone doesn't ache at all. Physically.
5. **Continuous rule:** when Igor feels "100% confident, I can do anything" — do one extra victory lap with NO new element. If you can ride and not escalate, you control the ego, not vice versa.

## BJJ Return Protocol

1. **Step 0:** text/call the coach. "I was out since February, knee was bothering me, want to return with control — can I come for technique only first week?" Coach says yes → shame drops 50%.
2. **Session 1:** technique drills only, 45 min, leave. Even if you feel you could stay for sparring.
3. **Session 2:** technique + light positional sparring (upper belt who controls strength).
4. **Sessions 1-4:** cap at 2 sessions/week. Not 3, not 4. Two. Even if you could do more.
5. **Knee red flag:** if it hurts, stop immediately. Not "one more round." The honor is in coming back next week, not in toughing it out.
6. **20% power rule:** week 1 → 20% of max. Week 2 → 40%. Week 3 → 60-70%. Full power only after ~1 month.

## The «100% disappears when I sit on the bike» Effect

When Igor sits on the bike, fear vanishes. This is exactly why crashes happen — fear is the only governor between 80% and 120%. Without it, he rides beyond his current technical ceiling.

**The counter:** recognize the feeling "I'm 100% confident, I can do anything" as a **danger signal**, not a green light. It means the governor is off. Lock in one extra easy lap as a discipline test.

## When Igor says «I'll just do sparring with people I know, carefully»

This is the same thought pattern that led to the pillow no-hander crash. Acknowledge it without arguing. Offer the protocol as an experiment: «Try one session technique-only. If it feels stupid, you can go back to sparring next time. One session.» This is lower resistance than «don't spar for a month.»
