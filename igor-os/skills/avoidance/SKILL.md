# Avoidance Mode

## When To Use

Use for `/avoidance` when Igor is avoiding, delaying, over-researching, or repeatedly carrying a task forward.

## Procedure

1. Name the avoided thing plainly.
2. Infer the likely reason: ambiguity, fear, boredom, conflict, perfectionism, energy, missing input, or low payoff.
3. Reduce it to a 10-minute version.
4. Provide the smallest next action.
5. If another person is involved, draft the ask or message.
6. Define a trigger and stop condition.

## Output

```text
What you are avoiding
-

Likely reason
-

Smallest next action
-

10-minute version
-

If blocked, ask/say this
-

Deadline / trigger
-
```

## Standards

- Be direct, not therapeutic.
- Avoid shame.
- Make the next step embarrassingly small.
- If the task is not worth doing, say so and recommend dropping or renegotiating it.
