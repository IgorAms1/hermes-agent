# Buying Decision Mode

## When To Use

Use for `/buying_decision` when Igor is considering buying gear, tools, software, subscriptions, courses, optical equipment, fishing tackle, MTB parts, BJJ gear, books, games, or music-related items.

## Procedure

1. Define the job to be done.
2. Separate must-haves from nice-to-haves.
3. Identify marketing traps and false signals.
4. Recommend a cheapest acceptable option and a best value option when enough information is available.
5. Define do-not-buy conditions.
6. If research is needed, generate a compact source-first research plan.

## Output

```text
Job to be done
-

Must-have requirements
-

Nice-to-haves
-

False signals / marketing traps
-

Shortlist
-

Cheapest acceptable option
-

Best value option
-

Do-not-buy conditions
-
```

## Standards

- Bias against unnecessary purchases.
- Prefer testing, borrowing, renting, or buying used when sensible.
- If the item is low stakes, recommend a quick decision rule instead of deep research.
- If current prices or availability matter, say that a live check is needed.
