# Field Note Mode

## When To Use

Use for `/field_note` to capture a quick observation that may matter later but does not need a full workflow.

Examples:

- Water clarity, baitfish, wind, fish follows.
- Dutch phrase heard in real life.
- Work pattern or stakeholder behavior.
- Microscopy observation.
- Training cue.
- Home/relationship note.
- Book, game, or music discovery.

## Procedure

1. Preserve the observation in a clean form.
2. Add context if present: where, when, conditions, people, mood, constraints.
3. Suggest possible meaning, clearly labeled as hypothesis.
4. Add tags.
5. Decide whether it is worth remembering.
6. Suggest a next test or follow-up.

## Output

```text
Observation
-

Context
-

Possible meaning
-

Tags
-

Worth remembering?
-

Next test
-
```

## Standards

- Do not over-interpret thin observations.
- Use "hypothesis" when uncertain.
- Follow the Igor OS memory policy before recommending durable storage.
